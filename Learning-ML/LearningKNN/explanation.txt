# 1️⃣ What is KNN?

**KNN = K-Nearest Neighbors**

It is a **supervised learning algorithm** used for:

* Classification
* Regression

### Core Idea

> A new data point is classified based on the labels of its nearest neighbors.

Simple meaning:
**“Look at nearby points and follow the majority.”**

---

# 2️⃣ Real Life Intuition

Imagine you want to predict:

Is a student **Pass or Fail**?

You get a new student:

* Study hours = 4
* Attendance = 60%

Now you check:

* Which students are closest to him?
* Suppose nearest 5 students:

```
Pass
Pass
Fail
Pass
Pass
```

Majority = Pass

So prediction = **Pass**

This is KNN.

---

# 3️⃣ What does “K” mean?

**K = number of neighbors**

Example:

* K = 3 → check 3 nearest points
* K = 5 → check 5 nearest points

### Effect of K

| K value | Result                       |
| ------- | ---------------------------- |
| Small K | Overfitting (very sensitive) |
| Large K | Underfitting (too smooth)    |

---

# 4️⃣ How does KNN find “nearest”?

It uses **distance**.

Most common: **Euclidean Distance**

Formula (for two features):

[
distance = \sqrt{(x1 - x2)^2 + (y1 - y2)^2}
]

Meaning:
Closer distance = more similar.

---

# 5️⃣ How KNN Works (Algorithm Steps)

For a new point:

1. Choose K
2. Calculate distance from all training points
3. Select K nearest points
4. Take majority vote (classification)
5. Return prediction

Important:

> KNN has **no training phase**
> It stores the data and calculates during prediction.

This is called:

### Lazy Learning

---

# 6️⃣ Why Feature Scaling is IMPORTANT

Because KNN uses distance.

Example:

| Feature | Range          |
| ------- | -------------- |
| Age     | 18–60          |
| Salary  | 10,000–500,000 |

Salary dominates distance → wrong results.

So always scale:

```python
from sklearn.preprocessing import StandardScaler
```

Trees don’t need scaling
**KNN must have scaling**

---

# 7️⃣ Coding KNN (Step by Step)

### Step 1: Import

```python
from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import train_test_split
```

---

### Step 2: Split Data

```python
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
```

---

### Step 3: Scaling (Important)

```python
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)
```

---

### Step 4: Train Model

```python
model = KNeighborsClassifier(n_neighbors=5)
model.fit(X_train, y_train)
```

---

### Step 5: Predict

```python
y_pred = model.predict(X_test)
```

---

### Step 6: Evaluate

```python
from sklearn.metrics import accuracy_score
print(accuracy_score(y_test, y_pred))
```

---

# 8️⃣ Choosing Best K

```python
for k in range(1, 21):
    model = KNeighborsClassifier(n_neighbors=k)
    model.fit(X_train, y_train)
    print(k, model.score(X_test, y_test))
```

Choose K with highest accuracy.

---

# 9️⃣ Advantages of KNN

* Simple
* No training time
* Works well for small datasets

---

# 🔟 Disadvantages

* Slow for large datasets
* Needs scaling
* Sensitive to noise
* Memory heavy

---

# 1️⃣1️⃣ When to Use KNN?

Use when:

* Dataset is small
* Data has clear clusters
* Similarity matters

Avoid when:

* Dataset is very large
* Too many features
