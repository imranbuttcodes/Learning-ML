# 1️⃣ What is SVM? (Idea)

**SVM = Support Vector Machine**

Goal (for classification):

👉 Find a line (or boundary) that separates classes **with maximum margin**

Example:

Two classes:

```
Class 0: ○ ○ ○
Class 1: ● ● ●
```

Many lines can separate them.

SVM chooses the one with the **largest gap** between classes.

This gap is called:

> **Margin**

---

# 2️⃣ What is Margin?

Margin = Distance between:

* the boundary (line)
* and the nearest points from each class

SVM tries to:

[
\text{Maximize Margin}
]

Why?

Because larger margin → better generalization → less overfitting.

---

# 3️⃣ What are Support Vectors?

Not all points matter.

Only the **closest points to the boundary** matter.

These are called:

> **Support Vectors**

They “support” the decision boundary.

Example:

```
○ ○ ○
○   ← support vector

------ boundary -----

●   ← support vector
● ● ●
```

If you remove other points → boundary doesn’t change.

---

# 4️⃣ Mathematical Form (Simple)

Decision boundary:

[
w \cdot x + b = 0
]

Where:

* **w** = weights (slope direction)
* **b** = bias
* **x** = input

Prediction:

[
\text{Class} =
\begin{cases}
1 & \text{if } w\cdot x + b \ge 0 \
0 & \text{if } w\cdot x + b < 0
\end{cases}
]

Looks like logistic regression, but training goal is different.

---

# 5️⃣ Hard Margin vs Soft Margin

### Hard Margin

Used when data is perfectly separable.

No mistakes allowed.

Not practical.

---

### Soft Margin (Real world)

Allows some misclassification.

Controlled by parameter:

## **C**

---

# 6️⃣ Important Hyperparameter: C

C controls trade-off:

| C value | Behavior                                            |
| ------- | --------------------------------------------------- |
| Large C | Less mistakes, small margin, may overfit            |
| Small C | More margin, allows mistakes, better generalization |

Think:

```
Large C → strict teacher
Small C → flexible teacher
```

---

# 7️⃣ What if data is NOT linearly separable?

Example:

```
○ ○ ○
  ●
○ ○ ○
```

No straight line can separate.

Solution:

## Kernel Trick

Transform data into higher dimension.

Example idea:

2D → 3D → becomes separable.

You don’t manually transform — kernel does it.

---

# 8️⃣ Common Kernels

### Linear

Straight line

Use when:

* Data is simple
* Features are many

---

### RBF (Most popular)

Non-linear boundary.

Default choice.

---

### Polynomial

Curved boundary.

---

# 9️⃣ When to use SVM?

Good for:

* Small to medium datasets
* High-dimensional data
* Text classification
* Image classification
* Complex boundaries

Not good for:

* Very large datasets (slow)
* Noisy data with many outliers

---

# 10️⃣ Feature Scaling (Very Important)

SVM is distance-based.

So:

```
Scaling → REQUIRED
```

Always use:

* StandardScaler

---

# 11️⃣ Coding Example

Basic SVM:

```python
from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import train_test_split
from sklearn.datasets import load_iris

# Load data
data = load_iris()
X = data.data
y = data.target

# Split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# Scaling (important)
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

# Model
model = SVC(kernel='rbf', C=1)
model.fit(X_train, y_train)

# Accuracy
print(model.score(X_test, y_test))
```

---

# 12️⃣ Important Parameters

```python
SVC(
    kernel='rbf',   # linear, rbf, poly
    C=1.0,          # regularization
    gamma='scale'   # kernel influence (for rbf)
)
```

### Gamma

Controls how far influence of a point reaches:

| Gamma | Effect                    |
| ----- | ------------------------- |
| High  | Complex boundary, overfit |
| Low   | Smooth boundary           |

---

# 13️⃣ Summary

SVM idea:

```
Find boundary with maximum margin
Use support vectors
Use kernels if data is non-linear
Scale features
Tune C and gamma
```
